# Student Task Manager

A simple React application built according to the assignment guidelines to help students practice components, JSX, conditional rendering, props, events, component composition, and form validation.

## Features
- Display list of tasks
- Add new task with validation
- Mark tasks as completed/pending
- Delete tasks with confirmation
- Conditional rendering for empty task lists
- Task statistics (Total, Completed, Remaining)
- Filter by All, Completed, and Pending
- Reusable Card component with `children` prop

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the application:
   ```bash
   npm start
   ```
